
# MUSE RPG Framework

This is a public repostitory for the MUSE RPG framework. For those who prefer a quick, local way to pull updates for the framework without relying on [muserpg.com](https://muserpg.com/) this is the best method we have found.

This repo will be regularly updated each time anything on the site changes.

The files are presented in markdown format, which can be read by most text editors. Personally we're big fans of [Obsidian.md](https://obsidian.md/) and [VSCodium](https://vscodium.com/), but a wide swath of different softwares will enable you to work with these files.

If you need help, we can be contacted on [Bluesky](https://bsky.app/profile/muserpg.com), via [Email](mailto:muserpg@tuta.com) , [Mastodon](https://mastodon.social/@muserpg), or our server on [Fluxer](https://fluxer.gg/t1ujSzOO).
